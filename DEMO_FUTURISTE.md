## 🎮 **CONTRÔLES FUTURISTES**

### ⌨️ **Raccourcis Clavier**
| Touche | Action |
|--------|--------|
| `1-8` | Sélectionner planètes (Mercure → Neptune) |
| `0` | Sélectionner le Soleil |
| `ESPACE` | Pause/Play animation |
| `R` | Reset vue d'ensemble |
| `O` | Toggle orbites |
| `L` | Toggle labels |
| `S` | Changer échelle |
| `F` | Focus sur objet sélectionné |
| `D` | Mode détaillé |
| `H` | Aide |
| `Échap` | Désélectionner |

### 🖱️ **Contrôles Souris**
- **Clic gauche + glisser** : Rotation caméra
- **Molette** : Zoom (adapté à l'échelle)
- **Clic sur planète** : Sélection + infos
- **Double-clic** : Focus détaillé
- **Survol** : Tooltip + highlight

### 🎛️ **Interface HUD**
- **Sliders de vitesse** : Orbites et rotations
- **Toggle échelle** : Réaliste ↔ Optimisée
- **Modes de vue** : Générale, Interne, Externe
- **Console de recherche** : Tapez nom de planète
- **Coordonnées temps réel** : Position caméra
